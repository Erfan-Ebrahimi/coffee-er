# Coffee Store

Persian coffee storefront UI built with React, Tailwind CSS and Vite, with product sections, Swiper carousels and theme switching.

<p dir="rtl">رابط فروشگاه قهوه با بخش‌های محصولات، اسلایدر و تغییر تم.</p>

[Deployment link](https://coffee-er.netlify.app) · [Source](https://github.com/Erfan-Ebrahimi/coffee-er)

## Stack

React · Tailwind CSS · Vite · Swiper · React Router

## What's inside

- Product categories and product showcase sections
- Swiper carousels
- Dark/light theme switching
- Articles, services and contact sections

## Local setup

```bash
git clone https://github.com/Erfan-Ebrahimi/coffee-er.git
cd coffee-er
npm ci
npm run dev
```

Create a production build with `npm run build`. Preview it locally with `npm run preview`.

## Project layout

- `src/components/` — storefront sections and product cards
- `src/pages/` — page components
- `src/Hooks/` — theme hook
- `src/routes.jsx` — route definitions

## Project notes

A front-end practice project focused on React and Tailwind CSS. Payment processing and a commerce backend are outside this repository.
